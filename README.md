# AI Chat Project

אפליקציית צ'אט המתקשרת עם מודל השפה GPT-5-NANO דרך ה-API של המכללה (IAC Student API), עם ממשק ויזואלי ב-Streamlit.

## דרישות מערכת
- Python 3.10+
- ספריות: streamlit, requests, python-dotenv

## התקנה
\```
pip install -r requirements.txt
\```

## הגדרת מפתח API
צרו קובץ בשם `.env` בתיקיית הפרויקט, והוסיפו בו את השורה:
\```
IAC_API_KEY=sk-std-YOUR-KEY-HERE
\```

## הוראות הפעלה

הרצת צ'אט ב-CLI:
\```
python main.py
\```

הרצת ממשק Streamlit:
\```
streamlit run app.py
\```
